[h1] BAB II  TINJAUAN PUSTAKA
[h2] 2.1  Vue.js dan Composition API
[para] Vue.js adalah framework front-end progresif yang bekerja pada lapisan tampilan (view layer). Kata progresif pada dokumentasi resmi Vue.js bermakna bahwa framework ini dapat diadopsi secara bertahap: mulai dari satu berkas HTML dengan satu berkas JavaScript, hingga menjadi arsitektur aplikasi lengkap dengan sistem routing dan manajemen state.
[para] Composition API yang diperkenalkan pada Vue 3 menyediakan cara mengorganisasi logika komponen secara eksplisit. Setiap komponen didefinisikan melalui fungsi setup() yang menerima props, lalu mengembalikan nilai yang akan diekspos ke template. Keunggulan utama Composition API terletak pada fleksibilitasnya: logika yang bersifat reusable dapat dipisah ke dalam composable, sehingga tidak terikat pada pemanggilan siklus hidup komponen tertentu. Pada laporan ini, logika pengelolaan data event dipisah ke dalam berkas src/composables/useEvents.js.
[para] Tiga API reaktif yang paling sering digunakan dalam implementasi ini adalah ref, computed, dan watch. ref digunakan untuk menyimpan nilai yang dapat berubah dan dapat di-two-way binding pada input. computed digunakan untuk menghasilkan nilai turunan yang dihitung otomatis, misalnya daftar event aktif. watch digunakan untuk melakukan efek samping, yaitu menyimpan state ke localStorage setiap kali data berubah.
[h2] 2.2  Vite sebagai Development Server dan Build Tool
[para] Vite adalah build tool untuk ekosistem JavaScript modern yang dikembangkan oleh tim yang sama dengan Vue.js. Dua keunggulan utama Vite dalam konteks praktikum adalah kecepatan start-up development server dan keluaran produksi yang ringkas.
[para] Pada fase pengembangan, Vite tidak memproses seluruh berkas aplikasi secara prematur. Sebaliknya, Vite menyajikan berkas source langsung melalui native ES Module sehingga start-up server hampir seketika. Pada fase build, Vite menggunakan Rollup untuk melakukan code splitting, tree-shaking, dan minification. Mekanisme ini terlihat langsung dari hasil build pada Tabel 4.4, setiap halaman dipecah menjadi berkas JavaScript terpisah, sementara bundle utama tetap berukuran ringkas.
[h2] 2.3  Vue Router dan Konsep Single Page Application
[para] Vue Router adalah pustaka routing resmi untuk Vue.js yang menyediakan mekanisme navigasi sisi klien. Dengan Vue Router, aplikasi dapat berjalan sebagai Single Page Application (SPA), yaitu aplikasi yang hanya memuat satu dokumen HTML dan melakukan penggantian tampilan di sisi klien tanpa memuat ulang seluruh halaman dari server.
[para] Konsekuensi dari pendekatan SPA adalah berkurangnya permintaan jaringan pada setiap perpindahan halaman, sehingga kemungkinan aplikasi terasa jauh lebih cepat dan cair. Namun SPA menuntut pengembang menyusun peta rute secara eksplisit, sehingga umumnya disertai komponen navigasi seperti Navbar dan Breadcrumb agar pengguna tidak kehilangan konteks posisi.
[h2] 2.4  Hierarki Parent–Child dalam Navigasi
[para] Pada aplikasi web berskala menengah, sekumpulan halaman tidak selalu berada pada level yang sama. Sebagian halaman merupakan kelompok yang memuat sejumlah halaman turunan, misalnya halaman Browse yang memuat daftar event dan halaman kategori. Relasi seperti ini dalam Vue Router direpresentasikan melalui properti children pada objek rute.
[para] Implementasi hierarki Parent–Child memiliki beberapa manfaat penting. Pertama, outlet dari parent dapat langsung merender children tanpa mengubah URL, sehingga URL tetap mencerminkan posisi pengguna secara utuh. Kedua, komponen Breadcrumb dapat menelusuri properti route.matched untuk membentuk jejak navigasi otomatis. Ketiga, menu navigasi dapat dibangun dari satu sumber kebenaran, yaitu array konfigurasi rute, sehingga struktur menu dan struktur URL tidak pernah berbeda.
[h2] 2.5  Komponen Reusable, Props, Emits, dan Slot
[para] Komponen dalam Vue.js adalah unit pembangun antarmuka yang dapat dipakai ulang. Empat mekanisme komunikasi antar komponen yang digunakan dalam laporan ini adalah props, emits, slot, dan v-model.

  const matched = route.matched;
  let crumbs = matched.map((m) => {
    let path = m.path;
    if (path.includes(':')) {
      path = route.path;
    }
    return { name: m.name, path: path, meta: m.meta };
  }).filter(m => m.meta && m.meta.breadcrumb);

  if (route.name === 'event-detail') {
    crumbs.splice(crumbs.length - 1, 0, {
      path: '/browse/events',
      meta: { breadcrumb: 'Event List' }
    });
  }

  if (crumbs.length === 0 || crumbs[0].meta.breadcrumb !== 'Home') {
    crumbs.unshift({ path: '/', meta: { breadcrumb: 'Home' } });
  }

});

[h2] 4.12  State Event dan Persistensi
[para] Seluruh data event dikelola pada composable useEvents.js. Composable ini menyimpan array event pada sebuah ref, kemudian menyediakan nilai turunan berupa jumlah event, event aktif, dan event selesai. Setiap mutasi data menggunakan fungsi create, complete, dan delete yang tersentralisasi sehingga konsisten di seluruh pemanggil.
[code] const STORAGE_KEY = 'gatherly_events';

const savedData = localStorage.getItem(STORAGE_KEY);
const events = ref(savedData ? JSON.parse(savedData) : defaultEvents);

watch(
  events,
  (newEvents) => {
    localStorage.setItem(STORAGE_KEY, JSON.stringify(newEvents));
  },
  { deep: true }
);

export function useEvents() {
  const totalEvents = computed(() => events.value.length);
  const activeEvents = computed(() => events.value.filter(e => !e.done));
  const completedEvents = computed(() => events.value.filter(e => e.done));

  const createEvent = (eventData) => {
    const newEvent = {
      id: Date.now(),
      title: eventData.title,
      date: eventData.date,
      loc: eventData.loc.startsWith('📍') ? eventData.loc : `📍 ${eventData.loc}`,
      cat: eventData.cat,
      quota: Number(eventData.quota) || 100,
      price: eventData.price || 'Free',
      desc: eventData.desc,
      done: false
    };
    events.value.unshift(newEvent);
    return newEvent;
  };

  const completeEvent = (id) => {
    const target = events.value.find(e => e.id === Number(id));
    if (target) { target.done = true; }
  };

  const deleteEvent = (id) => {
    const index = events.value.findIndex(e => e.id === Number(id));
    if (index !== -1) { events.value.splice(index, 1); }
  };

  const getEventById = (id) =>
    events.value.find(e => e.id === Number(id));

  return { events, totalEvents, activeEvents, completedEvents,
           createEvent, completeEvent, deleteEvent, getEventById };
}

[h2] 1.1  Latar Belakang
[para] Perkembangan teknologi antarmuka web telah mengubah cara manusia mengakses dan mengelola informasi. Aplikasi berbasis web modern tidak lagi sekadar menampilkan dokumen statis, melainkan menyediakan pengalaman interaktif yang dinamis, cepat, dan konsisten pada berbagai perangkat. Salah satu framework yang paling banyak digunakan dalam ekosistem tersebut adalah Vue.js.
[para] Vue.js merupakan framework front-end progresif yang dirancang oleh Evan You. Karakteristik utamanya terletak pada pendekatan reaktif dan deklaratif: pengembang cukup mendeskripsikan tampilan yang dikehendaki pada kondisi tertentu, sedangkan framework yang bertanggung jawab melacak perubahan state dan otomatis memperbarui antarmuka yang ditampilkan. Pada versi 3, Vue.js memperkenalkan Composition API berupa susunan setup() yang memberi keleluasaan pengorganisasian logika komponen sekaligus menutup keterbatasan Options API yang lazim digunakan pada Vue 2.
[para] Pada sisi toolchain, Vite berperan sebagai development server sekaligus build tool. Berbeda dengan bundler konvensional yang harus memproses seluruh berkas aplikasi sebelum halaman dapat disajikan, Vite memanfaatkan native ES Module sehingga proses start-up development server menjadi jauh lebih cepat. Kombinasi Vue.js dan Vite kemudian menjadi fondasi yang lazim dipakai pada praktikum pemrograman antarmuka web modern, termasuk pada mata kuliah Pengembangan UI Lanjut.
[para] Dalam konteks mata kuliah Pengembangan UI Lanjut, modul pertama (Modul 0) berfokus pada penyiapan environment pengembangan sehingga praktikan dapat membuat, menjalankan, dan menghentikan server lokal secara mandiri. Modul kedua (Modul 1) kemudian berfokus pada struktur aplikasi dan navigasi, yaitu penerjemahan konsep Site Map menjadi kode yang benar-benar berjalan melalui Vue Router, dengan penekanan pada hierarki Parent–Child, komponen Navbar sebagai alat transportasi pengguna, dan Breadcrumb sebagai penunjuk arah.
[para] Praktikum ini mendokumentasikan proses tersebut secara utuh, mulai dari instalasi Visual Studio Code, Node.js, dan npm, pembuatan kerangka project dengan generator create-vue, pengimplementasian hierarki Parent–Child pada src/router/index.js, hingga konstruksi komponen Navbar dan Breadcrumb beserta seluruh halaman destinasi pendukungnya. Sebagai kasus studi, project yang digunakan bernama belajar-vue dengan identitas produk Gatherly, sebuah platform komunitas event yang memadukan katalog publik dengan dasbor organizer.
