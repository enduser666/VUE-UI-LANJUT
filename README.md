# Pemrograman UI Lanjut (VUE-UI-LANJUT)

Repository praktikum mata kuliah Pengembangan / Pemrograman UI Lanjut.

## Branching Strategy
- **`main`**: Branch utama base repository.
- **`modul-0-1`**: Pengerjaan Modul 0 (Setup Vite & Vue 3) dan Modul 1 (Struktur Aplikasi, Vue Router, & Komponen Navigasi).
- **`modul-2`**: Pengerjaan Modul 2 (Layout, Spacing, Adaptive Grid, dan Dashboard Organizer).

## Menjalankan Project (Branch `modul-2`)
1. Berpindah ke branch modul:
   ```bash
   git checkout modul-2
   ```
2. Masuk ke folder project:
   ```bash
   cd belajar-vue
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Jalankan development server:
   ```bash
   npm run dev
   ```
